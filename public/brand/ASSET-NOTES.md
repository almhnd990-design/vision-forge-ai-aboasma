# GhostOps mascot

`ghostops-mascot.png` is a complete local image asset generated with the built-in image-generation tool using the user's attached GhostOps infographic as the identity reference. It is used by the hero, brand avatar, workspace empty state, and favicon.

Prompt specification: preserve the central dark hooded AI ghost, draped indigo cloak, black face, glowing cyan almond eyes, short rounded proportions, purple G on the chest, violet rim light and subtle cyan reflected light. Render one centered bust on a near-black charcoal background; no infographic, orange markup, generic robot, panels, border, or text except the G.

Manrope and Noto Sans Arabic are self-hosted from their Fontsource packages, which include their font license files. No remote font request is needed at runtime.
